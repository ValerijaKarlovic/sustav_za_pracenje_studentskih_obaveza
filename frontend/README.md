# Frontend (Vue 3)

Korisničko sučelje povezano na backend na `http://localhost:5099/api`.

## Preduvjeti

- Node.js (LTS)
- Pokrenut backend (pogledajte `../README.md` ili `../backend/README.md`)

## Pokretanje

```bash
cd frontend
npm install
npm run dev
```

- **Prvi put** (ili nakon promjene `package.json`): `npm install`
- **Svaki rad**: `npm run dev`
- Aplikacija: **http://localhost:5173/login**


### Produkcijski build (opcionalno)

```bash
npm run build
npm run preview
```
